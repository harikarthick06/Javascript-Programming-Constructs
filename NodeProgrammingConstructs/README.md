# NodeProgrammingConstructs

Collection of Node.js practice problems for programming constructs.

How to run any file:

```bash
node fileName.js
```

For command-line input:

```bash
node fileName.js 2024
```

Examples:

```bash
node sequence.js
node dateCheck.js 25 3
node leapYear.js 2024
node switchPractice.js 1 5
```
